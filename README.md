## What's this about?

Basically, we're building a simple desktop app to help people manage daily tasks. 
We all know how easy it is to lose track of assignments, work deadlines, or even 
personal stuff. This app is supposed to be a one-stop place to create, organize, 
and track tasks without the clutter. Still early stage, but we think it'll be 
handy for students and professionals alike.

---

## Planned Features (still subject to change)

- Add, edit, and delete tasks
- Mark tasks as done / not done
- Categorize tasks (Work, School, Personal, Urgent, etc.)
- Set due dates and priority levels (High, Medium, Low)
- Filter tasks by category or status
- Sort tasks by date, priority, or category
- Search for specific tasks by name
- Auto-save everything to a local database (no cloud, no accounts)
- Clean GUI using Tkinter

---

## Tech Stack (as of right now)

- **Python 3** – main language
- **Tkinter** – for the GUI (built-in, so no extra installs)
- **SQLite** – local database, stores everything in a single `.db` file
- **Git/GitHub** – version control (obviously)

We picked these because we're already somewhat familiar with them, and they 
keep things lightweight. No internet required, which is a plus.
